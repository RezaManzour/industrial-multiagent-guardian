# Security policy

## Supported versions

Only the latest commit on the `main` branch receives fixes.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report them privately through GitHub instead: open the
[Security tab](https://github.com/RezaManzour/industrial-multiagent-guardian/security) of this repository and choose **Report a vulnerability**.
You will get an acknowledgement within a few days, and the fix (if any) will be credited to
you unless you prefer otherwise.

Please include what you found, how to reproduce it, and its possible impact.

## Scope

This is a research and portfolio project, not a production service. Never commit real API
keys or credentials; use the `.env` file, which is ignored by git.
